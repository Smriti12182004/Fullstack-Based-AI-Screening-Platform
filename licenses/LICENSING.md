# Licensing

## Project source

No general open-source licence is currently provided for Evalyn's own source
code. Repository visibility does not grant permission to reuse the project code.

## Third-party dependencies

See [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt) for collected dependency
notices. Verify coverage against the exact dependencies included in each release.

## Model licence

The [Llama 3.2 Community License](llama3.2-community-license.txt) is retained
for the model integration where applicable. Its presence does not license
Evalyn's own source code.

## Release verification

The collector gathers evidence from installed environments. It does not
independently verify the final deployed image, all model artefacts, provider
terms, or every licence obligation. Complete release-specific verification
before claiming licensing clearance.
